# موقع بساط للأثاث والمفروشات
موقع عربي متجاوب متخصص في السجاد والموكيت فقط.
- `index.html`: الصفحة الرئيسية، بيانات SEO والبيانات المنظمة.
- `styles.css`: التصميم المتجاوب.
- `assets/`: الصور والفيديوهات المرفقة وأيقونة الموقع.

## قبل النشر
2. النطاق المعتمد: https://besaatkuw.com/ (ملف CNAME في جذر المستودع — لا تحذفه).
3. انشر الموقع على الاستضافة ثم أرسل sitemap إلى Google Search Console.
4. رقم السجل التجاري المدرج: 475436. لم أضف عنوانًا جغرافيًا غير مزوّد.
SEO يهيئ الصفحة تقنيًا ومحتوائيًا، لكنه لا يضمن ترتيبًا محددًا أو فهرسة فورية.

## إضافة المنتجات (صفحة admin)
- افتح `/admin/` من الهاتف، الصق مفتاح GitHub مرة واحدة (يُحفظ على الجهاز فقط).
- أدخل اسم المنتج، التقط صورة أو اخترها من المعرض، اكتب الوصف، ثم «إضافة المنتج».
- تُضغط الصورة على الهاتف وتُحفظ في `assets/works/`، ويُحدَّث `products.json` وقسم «آخر أعمالنا» في `index.html` في عملية حفظ واحدة؛ يظهر المنتج خلال دقيقة إلى دقيقتين.
- القسم مكتوب داخل HTML مباشرة (وليس عبر JavaScript) ليقرأه Google.
- لا تعدّل يدويًا ما بين علامات `<!--LATEST:START-->` و`<!--LATEST:END-->`.

## صفحات المنتجات وخريطة الموقع
- كل منتج له صفحة مستقلة: `/products/<اسم-المنتج>/`.
- `sitemap.xml` يُولَّد بالكامل من `products.json` (الرئيسية + كل منتج وصوره).
- لوحة الإدارة تضيف/تحذف صفحة المنتج وتحدّث الصفحة الرئيسية وخريطة الموقع في عملية حفظ واحدة.
- المولّد واحد: `admin/render.js`. بعد تعديل القالب شغّل `node tools/rebuild.js` لإعادة توليد كل الصفحات.
